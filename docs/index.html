How it works

Three steps, two real data sources

01

Pull hyperlocal temperature

For each U.S. location, call the FortyGuard Temperature API (/v1/heatmap) and poll until the 2-metre ambient temperature is ready.

02

Merge in a real outcome

Join that temperature to a real-world, non-weather outcome — here, CDC heat-illness ED visit rates by HHS region.

03

Test the relationship

Run a Pearson correlation and linear regression to quantify the strength and significance of the link — not just eyeball a trend.

Data sources

Two real, published datasets — no synthetic numbers in the final result

Temperature

FortyGuard Temperature API

2-metre ambient air temperature, 15 July 2024, 14:00 local (peak-heat hour), for 20 U.S. cities.

Health outcome
